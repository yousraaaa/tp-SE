# Simulation de tunnel à sens unique pour bus

Ce projet simule le passage de bus entre deux villes (X et Y) via un tunnel à voie unique.
Les règles suivantes sont respectées :
- Aucun croisement dans le tunnel
- Plusieurs bus peuvent passer dans le même sens
- Pas de famine (équité assurée entre les directions)
